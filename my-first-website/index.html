Una lista en general, por ejemplo una sin orden se crea con

<ul>
    <li>naranjas</li>
    <li>peras</li>
    <li>uvas</li>
    <li>kiwis</li>
</ul>

Para crear una lista rápidamente, se puede utilizar las abreviaciones Emmet, por ejemplo, una lista ordenada de 5 elementos se crea con ol>li*5
